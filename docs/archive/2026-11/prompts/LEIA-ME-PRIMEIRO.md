# ATLAS — Prompts 13–24 V2

Este pacote **substitui os prompts originais 13–24**, sem remover sua versão anterior. Foi elaborado a partir dos anexos originais 05–24, considerando o Angular já implantado, a direção A/Stitch e os requisitos de exploração interativa.

## Uso

1. Faça backup/commit do repositório local antes de substituir os arquivos sob `prompts/`.
2. Copie **somente os 12 arquivos numerados** para a pasta `prompts/` do projeto, substituindo os homônimos correspondentes. Preserve 00–12 e demais arquivos.
3. Leia `AUDITORIA-E-DECISOES.md`.
4. No Codex, envie: `Execute integralmente prompts/13-atlas-de-marxismo-e-comunismo.md. Inspecione a base atual e faça mudanças reais com testes. Não execute o próximo prompt.`
5. Revise implementação real, screenshots, fontes e pendências antes do próximo. Nenhuma etapa concede revisão editorial humana automaticamente.

**Importante:** os prompts não incluem nem alteram o repositório Angular. São instruções de execução para Codex, não código já implementado. Nem toda etapa precisa introduzir nova biblioteca de visualização.
