# ATLAS V4 Implementation Plan

**Goal:** entregar o padrão V4 e a primeira página contínua de Marxismo.
**Architecture:** schema Zod de apresentação separado dos fatos; JSON por domínio; componentes Angular standalone reaproveitados.
**Tech Stack:** Angular 21, Signals, SCSS, Zod, Vitest, Playwright existentes.
**Spec:** docs/superpowers/specs/2026-11-01-atlas-v4-design.md e docs/PAGE_STANDARD.md.

Sem novas dependências, backend, push ou publicação. Preservar fontes, licenças, rotas secundárias e estados editoriais. Trabalho na branch codex/atlas-v4.
